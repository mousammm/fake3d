# fake3d

Fully softwared renderer in C using SDL2.

## demo

https://github.com/user-attachments/assets/53400d86-8a3b-4e47-bdc8-2f95c966bbe8

## building and running
```
$ gcc -o fake3d src/main.c -lSDL2 -lm
$ ./fake3d
```
